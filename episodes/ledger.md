# Ledger

What each episode used, so the next one does not use it again. Add a section for every episode in
the same change as its script. `scripts/episode.py` enforces the first of these (site tips) and
reports the second and third (repeated lines, shared stickers); the rest is on whoever writes.

## Site tips

One per episode, never repeated. The name goes in the script's `"site_tips"`.

| Tip | What to say about it | Used |
